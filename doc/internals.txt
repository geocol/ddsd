* Item object

type

    file                      A file.
    meta                      A metadata file.
    mirrorzip                 A mirrorzip.
    package                   A package.  For archives, it represents the
                              archive file.  Otherwise, a virtual object.

path [Path::Tiny?]

    The path, to the file in the local file system, of the file's
    bytes, if there is a local copy of the file available.

archive_meta (when with_source_meta => 1)

    Properties of the entire archive, if it is a |package|
    representing an archive file.

  comment [text?]

    The comment of the archive, as a character string.

  comment_encoding

    The encoding label of the comment of the file, used to decode byte
    string of |raw_comment| to obtain character string |comment|, if
    applicable.

  raw_comment

    The comment of the archive, in the raw format.  It can be a byte
    string or a character string, depending on the data type of the
    comment.  Missing when an archive-format-specified fixed encoding
    is used.

archive_item [Archive Item]? (when with_source_meta => 1)

    Properties of the file from the archive, if it is a |file|
    representing a file in an archive file.

source (when with_source_meta => 1)

    Properties of the data source of the file.

  url

    The URL of the file to be fetched, if any.

rev

    Physical properties of the file.  They are immutable
    characteristics of the file as of when it is put into the local
    data repository set for the first time.

  from_mirrorzip [boolean]

    True if the item is imported from a mirrorzip.

  http_etag

    The HTTP |ETag| response header's value, if any.

  http_incomplete [boolean]

    True if the file comes from HTTP and is terminated prematurely.

  insecure [boolean]

    True if the file comes from an insecure source.

  length (required)

    The byte length of the file's bytes.

  mime_filename

    The MIME file name of the file, if any.

  sha256 (required)

    Base16 of SHA-256 hash of the file's bytes.

  timestamp [time] (required)

    The time when the file is put into the local data repository set
    for the first time.  For the file imported from a mirrorzip, it is
    same as the mirrorzip's source file's |rev| object's |timestamp|
    value.

  http_content_type

    The HTTP |Content-Type| response header's value of the file, if
    any.

  http_date [time?]

    The HTTP |Date| response header's value of the file, if the file
    comes from HTTP.

  http_last_modiied [time?]

    The HTTP |Last-Modified| response header's value of the file, if
    any.

  url

    The URL of the file, if any.

  original_url

    The original URL of the file before any redirect.  Required if
    |url| is specified.

  raw_path

    The raw path to the file, if any.

package_item

    Computed properties of the item.

  file_name [text?]

    The file name of the item, if any.  It may or may not have path to
    the file in some platform conventions.

  title [text] (required)
  lang
  dir
  writing_mode

  desc [text?]

    A human-readable description for the item, if any.

  author
  org
  
  mime (required for |file|)

  file_time [time?]

    For a |file|, the file's timestamp, if known.

    For a |package|, the maximum (latest) of the files' timestamps,
    the package's manifest's timestamp, if applicable, and the
    package's file's timestamp, if applicable.

  tzoffset [number?]

    The local time offset from UTC, i.e. local time - UTC, in seconds,
    for the file's timestamp, if known.

  legal
  snapshot_hash

* Archive Item object

An Archive Item object represents a member of archive, such as ZIP.

path (required)

  Path to the member in the archive, as a character string.

path_encoding

  The encoding label of the path to the member, used to decode bytes
  to obtain character string |path|, if applicable.  Missing when an
  archive-format-specified fixed encoding is used.

comment [text?]

  The comment of the member in the archive, as a character string.

comment_encoding

  The encoding label of the comment of the member, used to decode
  bytes to obtain character string |comment|, if applicable.

mtime [time?]

  The modified time of the member, if known.

birthtime [time?]

  The created time of the member, if known.

tzoffset [number?]

  The local time offset from UTC, i.e. local time - UTC, in seconds,
  for the member's timestamps, if known.

is_directory [boolean]

  True if the member is a directory.

central [Archive Item Meta?]

  Metadata for the member in the central data structure of the
  archive, if any.

local [Archive Item Meta?]

  Metadata for the member in the member-local data structure of the
  archive, if any.

* Archive Item Meta object

An Archive Item Meta object represents a set of metadata for a member
of archive, such as ZIP central directory header or ZIP local header.

byte_length [integer?]

  The byte length of the uncompressed data of the member, if known.
  It might or might not be equal to the actual length of the file
  stored as the member, depending on the archive format.

raw_path [bytes?]

  Path to the member in the archive, in the raw format.  It can be a
  byte string or a character string, depending on the data type of the
  path.

raw_comment [bytes?]

  The comment of the member in the archive, in the raw format.  It can
  be a byte string or a character string, depending on the data type
  of the comment.  Missing when an archive-format-specified fixed
  encoding is used.

zip_general_purpose_bit_flag [integer?]

  The value of the general purpose bit flag of the member, if it is a
  member of ZIP.

zip_raw_last_mod_file_date_time [integer?]

  The value of the last mod file date and last mod file time fields,
  interpreted as an unsigned integer, of the member, if it is a member
  of ZIP.

zip_ntfs_mtime [number?]
zip_ntfs_atime [number?]
zip_ntfs_birthtime [number?]

  The values of the 0x000A timestamp fields of the member, if it is a
  member of ZIP and is specified.

zip_ext_mtime [time?]
zip_ext_atime [time?]
zip_ext_birthtime [time?]

  The values of the 0x5455 timestamp fields of the member, if it is a
  member of ZIP and is specified.

infozip_unix_mtime [time?]
infozip_unix_atime [time?]

  The values of the 0x5855 timestamp fields of the member, if it is a
  member of ZIP and is specified.

zip_unix_mtime [time?]
zip_unix_atime [time?]

  The values of the 0x000D timestamp fields of the member, if it is a
  member of ZIP and is specified.
